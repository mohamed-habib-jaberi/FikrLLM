# Directory `fikrllm.assets.notebooks`

This directory contains educational notebooks used to inspect and explain the model components.

## Notebooks

| Notebook | Role |
|---|---|
| `tokenizer_embeddings.ipynb` | Explores tokenizer loading, text normalization, encoding, decoding, and embeddings. |
| `attention-step-by-step.ipynb` | Explains causal self-attention step by step. |
| `model-step-by-step.ipynb` | Walks through the construction of the GPT model. |
| `chinchilla_llm_prompt.md` | Prompt/notes for reasoning about Chinchilla-style token-to-parameter ratios. |

## Notes

These files are for learning and inspection. They are not required by the training or generation entry points.
