# Directory `scripts.assets`

This directory contains helper assets used by data-preparation scripts.

## Files

| File | Role |
|---|---|
| `translategemma_chat_template.jinja` | Chat template used when formatting translation prompts for TranslateGemma/vLLM workflows. |

## Usage

The assets here are not model weights and are not part of runtime inference. They support scripts that prepare or transform datasets before training.
